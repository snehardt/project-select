# Project Select

This is my portfolio website for showing the games and other projects I have worked on. People can search for projects, see pictures, and find links to play or view the code.

[Visit the website](https://spencerehardt.pythonanywhere.com/)

## Instructions for Build and Use

Steps to build the software:

1. Make HTML pages with CSS.
2. Add Python and Django to load project information onto the pages.
3. Add a database to store the projects.
4. Add a search box and check the user's input.
5. Put the website online with PythonAnywhere.

Instructions for using the software:

1. Open the website using the link above.
2. Browse the projects or use the search box.
3. Click a project to see more information, pictures, and links.

## Development Environment

* Python 3.13
* Django 5.2.18
* HTML, CSS, and JavaScript
* SQLite database
* PythonAnywhere for hosting
